Flashcard Quiz App

About the Project

The Flashcard Quiz App is a simple learning application that helps users study and remember information using question-and-answer flashcards.

Features

- Display questions and answers.
- Show Answer button to reveal answers.
- Next and Previous navigation.
- Add new flashcards.
- Edit existing flashcards.
- Delete unwanted flashcards.
- Simple and user-friendly interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start using the Flashcard Quiz App.

Project Purpose

This project was developed as part of the CodeAlpha App Development Internship to improve practical application development skills.
