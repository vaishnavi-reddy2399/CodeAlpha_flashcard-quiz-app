## 📖 About The Project

The **Flashcard Quiz App** is a simple and interactive learning application designed to help users study and remember information using question-and-answer flashcards.

Users can reveal answers, navigate between flashcards, and create and manage their own flashcards easily.

## ✨ Features

- 📌 Display questions and answers.
- 👀 **Show Answer** button to reveal answers.
- ⏮️ **Previous** button to navigate to the previous card.
- ⏭️ **Next** button to move to the next card.
- ➕ Add new flashcards.
- ✏️ Edit existing flashcards.
- 🗑️ Delete unwanted flashcards.
- 🎨 Simple and user-friendly interface.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the application |
| CSS3 | Styling and layout |

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the Flashcard Quiz App!
